# 设计
用户已授权本地实现、审查与交付；真实上传单独由应用显式选择便签授权，默认关闭。
复用PR4的NoteContent三路合并算法；维持现有lossless v1/v2文件兼容，不做隐式迁移。
CloudKit private custom zone持久存储内容/颜色/删除墓碑；不上传notes.json、frame、visible或其他本地扩展。
设置入口展示签名/账户状态、选择首次上传便签、启停、立即同步、冲突解决及删除。初始不预选任何旧便签。
本地sync ledger原子写入成员、共同祖先、系统字段、账户绑定及冲突。先持久化成员，应用远端到notes成功后再确认祖先；重启重复应用仍安全。本地删除先持久化墓碑，再删除本地投影。
每轮拉取完整custom zone变化流（从nil token开始、处理分页），保留墓碑。使用ifServerRecordUnchanged上传；冲突保留双方，由用户选择本机或云端版本。账户变化暂停，禁止跨账户自动迁移。
停止同步后不启动新请求；已经发出的请求可能完成，保留本地数据和同步历史。网络失败保留本地修改，后续重新读取祖先/本地/远端后重试。
未签名或container entitlement不匹配时，在构造CKContainer之前禁用网络路径。可编译CloudKit API不代表真实服务可用。


## 用户选定 iCloud Drive 文件夹路线
父流程授权此替代路线。系统目录选择器只授权用户选择的文件夹，持久 bookmark，不扫描云盘。
在所选父目录创建唯一子目录。manifest 固定 UUID，events 为内容哈希命名的不可变修订。
NSFileCoordinator 保护本机读写，跨设备并发依靠 DAG 多头保留，不依赖文件协调实现跨设备互斥。
有多个不同值时显示每个版本，显式选择生成合并所有已见父节点的新修订。
缺父节点、摘要不匹配、格式异常和过期写入均暂停，不覆盖。
删除为墓碑，历史仍含旧正文，UI 和文档明确说明。
文件夹身份不等于 Apple 账户绑定。每次启动必须重新显式启用，运行时账户变化暂停。
设置中互斥禁用旧引擎控制，提交切换前复核旧实例 off/idle 与本地写权限。
无存储锁实例不得写停用标记或 folder choice。每个 scope 重置首次选择。
