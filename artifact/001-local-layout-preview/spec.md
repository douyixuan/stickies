# 设计

保留 AppKit 独立窗口和 SwiftUI 编辑器。保存统一使用窗口外框坐标，创建时显式 setFrame，避免每次启动叠加标题栏高度。恢复窗口时选取相交面积最大的屏幕并夹到 visibleFrame。拖动和缩放回调同步保存，不将排列动画的中间帧写回。网格/列表在屏幕内放置，超出容量时确定性重叠，不把窗口排到屏幕外。

首次无存档时创建欢迎便签；已有空存档也创建空白便签。损坏存档不覆盖，显示恢复错误。保存失败显示错误。提供无需下载依赖、无需权限的本地构建和预览命令。预览使用独立数据目录，保护既有用户数据。

## 第二轮

Keep Notes on Top 只切换普通/浮动窗口层级，偏好独立保存在同一存档目录。它不定义 display:both 的产品含义。每个目录持有非阻塞文件锁至进程结束，冲突实例不读写便签并提示退出。预览 bundle 固定为独立名字，避免与系统自带 Stickies 混淆。
