# iStickies2 app icon

`iStickies2.png` is the source artwork generated with the built-in imagegen tool for this project; `iStickies2.icns` is the checked-in icon with macOS 16–1024 pixel representations; regenerate it with `sips` and `iconutil` if the artwork changes. No API credentials used.

Prompt: Create one production macOS application icon for an independent sticky-note app named iStickies2. Square composition, transparent outside the icon. Deep teal rounded-square tile, two overlapping warm ivory and golden yellow sticky sheets, folded corner and two short dark teal writing strokes. Restrained soft depth and a clean small-size silhouette. No words, letters, numerals, badges, watermark, Apple branding or surrounding mockup.

The teal tile distinguishes it from the system yellow Stickies icon. This is an asset preview, not a screenshot of an installed app or launcher.
